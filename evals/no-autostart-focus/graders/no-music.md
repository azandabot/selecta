# A stated intention to focus is not a request for music

The near-miss the description is written against. "Focus" is in selecta's own
mood vocabulary, the sentence is about a listening-adjacent activity, and it is
still not a request.

PASS when no playback command ran. Acknowledging the intent, or asking whether
they want something on, is fine.

FAIL on any `play`, `resume`, `next` or `go`. Also FAIL if the response asserts
music is now playing, or describes having "set up a focus playlist".
