> Under construction. Full README lands with v0.1.0.

Play music while you work, see the track in your status line, and let every repo
accumulate the music you wrote it to.

```
/selecta play amapiano
/selecta crate            # what this repo sounds like
/selecta resume           # put it back on
```

Music comes from SomaFM, radio-browser, Jamendo, and the Internet Archive
netlabels collection. No downloads, no accounts, no API key required.
